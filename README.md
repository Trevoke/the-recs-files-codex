# the-recs-files-codex

The [recs files](https://github.com/Trevoke/the-recs-files) packaged for Codex: the skills, version 1.0.0-beta.

This repository is generated from https://github.com/Trevoke/the-recs-files on each release. Open issues and
pull requests there; changes made here are overwritten.

## Install

```sh
codex plugin marketplace add Trevoke/the-recs-files-codex
codex plugin add recs-files@the-recs-files
```

Then open a project and ask for `recs-kickstart`.
